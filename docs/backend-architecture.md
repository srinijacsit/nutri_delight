# Nutri Delight Architecture

## Frontend
Next.js + React + TypeScript

## Backend
Node.js + Express + TypeScript REST API

## Database
Supabase PostgreSQL

## Authentication
Supabase Auth

## Storage
Supabase Storage

## External integrations

PDF generation

```
Customer Browser
      ↓
Next.js Frontend
      ↓
Express REST API
      ↓
Business Logic
      ↓
Supabase PostgreSQL / Auth / Storage
```
